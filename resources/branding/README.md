# Aset logo

`logo-light.svg` merupakan penelusuran vektor simbol monogram dan gear dari `logo.jpeg`, mempertahankan proporsi referensi. Teks nama tetap memakai elemen landing page yang sudah ada. Versi gelap mengganti gear menjadi putih; bentuk monogram tetap sama. PNG transparan dirender dari SVG pada 512 × 535 piksel, dengan padding.

Ini rekonstruksi vektor dari JPEG, bukan file master resmi; tepi bevel/artefak JPEG tidak ditiru. File master perusahaan dapat diunggah lewat Pustaka Media bila tersedia. Original `logo.jpeg` tetap disimpan.

`php artisan cms:prepare-brand` memasukkan dua PNG ke media dan mengisi pilihan logo/favicon draft yang kosong. Pengulangan tidak mengganti pilihan admin atau snapshot publik.
